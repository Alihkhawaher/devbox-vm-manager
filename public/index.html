VM templates (base images)

    

    
Every sandbox is an instant copy-on-write clone of a template. Freeze a configured sandbox
      (Settings tab) to turn it into a reusable template — e.g. one with Docker already installed.

Run an app from a Docker image

    

      Paste an image reference and press the button. The manager creates a
      Docker-capable sandbox, boots it, pulls the image, works out its ports and
      volumes, starts it and gives you the URL — no existing VM needed.
      Ports you name below are applied at boot, so nothing has to restart.
